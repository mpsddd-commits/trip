## 3. 폼 검증과 요청 (WBR-10 ~ WBR-16)

| ID | 규칙 | 근거 |
|---|---|---|
| **WBR-10** | 폼 검증 상한은 **`GET /api/config` 의 `limits` 를 사용**한다. 프론트에 숫자를 하드코딩하지 않는다 | 서버 상한(BR-01·02)과 어긋나면 사용자가 이유 없이 거부당한다 |
| **WBR-11** | 폴링 간격: 경과 0~10초 **1초**, 이후 **2초**, **90초 초과 시 중단** + 수동 새로고침 안내 | Q2=A, NFR-1(60초)에 여유 |
| **WBR-12** | 문서가 백그라운드면 폴링을 멈추고, 복귀 시 즉시 1회 조회한다 | 불필요한 서버 부하 방지 |
| **WBR-13** | 진행 단계는 서버의 `step` 을 **사용자 언어로 번역**해 표시한다(6종). 진행률은 서버 `progress` 를 그대로 쓴다 | WBR-04 |
| **WBR-14** | 편집 API 응답(여행 전체)으로 캐시를 **직접 갱신**하고 추가 GET 을 하지 않는다 | Q1=A. u1 편집 API 가 전체를 반환 |
| **WBR-15** | 편집 성공 시 무효화 대상은 **`['trip', tripId]` 뿐**이다. 검색·추천 캐시는 유지한다 | 불필요한 외부 호출 방지 (NFR-4) |
| **WBR-16** | 모든 요청에 `X-Correlation-Id` 를 보내지 않는다. **서버가 발급한 값을 응답에서 받아 표시**한다 | u1 이 이미 발급·전파한다 |

## 4. 편집 상호작용 (WBR-17 ~ WBR-19)

| ID | 규칙 | 근거 |
|---|---|---|
| **WBR-17** | 드래그 순서 변경은 **낙관적 업데이트**한다. 실패 시 원래 순서로 되돌리고 토스트를 띄운다 | Q7=A |
| **WBR-18** | 🔴 **FR-19 는 "동시 표시"가 아니라 "상태 연속성"으로 만족한다.** 모바일 탭 전환 시 `selectedItemId` 를 유지하고, 전환 후 해당 항목으로 스크롤·뷰포트 이동한다 | Q6=A × FR-19 충돌 해소 (WD-1) |
| **WBR-19** | 일자 간 이동은 **드래그 + 컨텍스트 메뉴 두 경로**를 모두 제공한다. 모바일에서 탭을 넘는 드래그가 어렵기 때문 | Q8=A |

## 5. 표시 규칙 (WBR-20 ~ WBR-24)

| ID | 규칙 | 근거 |
|---|---|---|
| **WBR-20** | 일자 헤더에 총 이동시간·총 체류시간을 표시한다. 값은 서버 데이터에서 **파생 계산만** 한다 | WBR-04 |
| **WBR-21** | 항목 경고 4종을 배지로 표시한다: 고정시각 충돌 / 하루 종료 초과 / 영업시간 밖 / **이동시간 추정** | BR-32~35, BR-27 |
| **WBR-22** | 🔴 **추정 이동시간에는 반드시 "추정" 배지를 붙인다.** 확정값처럼 보이게 하지 않는다 | CON-1, BR-27 |
| **WBR-23** | 지도 경로선: 자동차(실경로)=**실선**, 도보·대중교통=**점선**. 범례로 의미를 설명한다 | FR-16, BR-27 |
| **WBR-24** | 마커는 **번호 + 일자 색상 + 일자 라벨** 3중으로 표기한다. 색상만으로 정보를 전달하지 않는다 | NFR-6, Q10=A |

## 6. 부분 결과와 미해결 장소 (WBR-25 ~ WBR-29)

| ID | 규칙 | 근거 |
|---|---|---|
| **WBR-25** | 🔴 `partial` 은 **구체적으로** 알린다: "N곳을 찾지 못했습니다", "일부 이동시간은 추정치입니다" | DD-23, Q13=A |

| **WBR-28** | 🔴 **딥링크 URL 생성은 W13 한 곳에만 존재한다.** u3 는 URL 을 만들지 않는다 | DD-11 |
| **WBR-29** | "확인 필요" 패널은 **접이식으로 상시 노출**한다. 닫아도 개수 배지는 남는다. 각 항목에 [직접 검색해 담기] 를 제공한다 | Q13=A, BR-18 의 사용자 측 대응 |

## 8. 오류·오프라인 (WBR-33 ~ WBR-36)

| ID | 규칙 | 근거 |
|---|---|---|
| **WBR-33** | 오류 표시는 **"어떤 동작이 실패했는지(프론트) + 백엔드 고정 문구"** 로 조립한다. `correlation_id` 는 접어둔 상세에 넣는다 | Q15=A, BR-58 |

| **WBR-36** | 온라인 복귀 시 `['trip', *]` 를 재검증한다. **서버가 항상 우선**이다 | CA-6, OUT-6 |
